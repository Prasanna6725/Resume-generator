# Resume Generator

A **live resume generator** built with **HTML, CSS, and JavaScript**.  
Users can enter their personal details, preview a clean resume, and download it as a **PDF** instantly — no backend required. Perfect for sharing or creating resumes on the fly.

---

## 🌐 Live Demo

The generator is hosted on **GitHub Pages**:  

[View Resume Generator Live](https://Prasanna6725.github.io/Resume-generator/)


---

## 📝 Features

- Live form to input:
  - Full name, title/role
  - Contact info: email, phone, location
  - Summary, education, experience, projects, skills
- Real-time resume preview
- Download as **PDF** with a single click
- Responsive and clean design
- Print-friendly layout

---

## 🚀 How to Use

1. Open the live demo or your local `index.html`.
2. Fill in your details in the form panel on the left.
3. The resume preview updates automatically on the right.
4. Click **📄 Download PDF** to save your resume.
